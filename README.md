# Electric UAV Energy, Thermal and Lightweight Design

This project analyses the main energy, thermal and lightweight design aspects of a small electric UAV.

The work includes aerodynamic calculations, mission energy estimation, battery sizing, thermal behaviour and a lightweight comparison using a CFRP wing spar.

## Main results

- Initial UAV mass: 12 kg
- Battery optimized mass: 8.51 kg
- Final mass with CFRP spar: 7.80 kg
- Initial mission energy: 334.46 Wh
- Final mission energy: 286.53 Wh
- Total energy saving: 14.33%
